# Kroppen lyver ikke (men du tolker feil)

Manual i kroppsspråk. Rå, praktisk, forskningssjekket. ~150 sider A5.

- **`manual.pdf`** – ferdig utskriftsversjon (A5)
- **`manual.html`** – samme innhold, åpnes i nettleser (lys/mørk modus)
- **`kapitler/`** – kildetekst, ett kapittel per fil (Markdown)

Bokser: FELTBOKS (praktisk) · FAKTA-GRANAT (forskning) · MYTEKNUSER · FLINK PIKE-ALARM (din egen kropp) · SJEKKLISTE.

Bygg på nytt etter endringer: `./bygg.sh` (krever pandoc + Playwright/Chromium).
