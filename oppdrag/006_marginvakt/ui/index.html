Eksporter nøkkeltall (CSV)
Definisjoner. Inntekt = prosjektpris (eks. mva) i valgt versjon. Direkte kostnader = underleverandører + andre kostnader. Refusjoner (viderefakturerte utlegg) vises separat og inngår verken i inntekt eller kostnad. Dekningsbidrag = inntekt − direkte kostnader. Effektiv timeinntekt = dekningsbidrag / faktiske timer. Internkost = timer × timesats gyldig på timens dato. Rapporter er frosne øyeblikksbilder.
