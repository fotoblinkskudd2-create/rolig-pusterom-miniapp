# DAILY_EXECUTOR_NODE — 50 konkrete handlinger for i dag

Ingen "meditér 10 min". Alt er tied til faktiske pågående prosjekter: AI Empire, droner, gonzo content, vibe coding, patenter, mental stack.

## AI Empire / agent-arkitektur (1-10)
1. Bygg CRITIC-node inn i én eksisterende agent-pipeline før lunsj — test på gårsdagens output
2. Sett hard token-cap på alle loop-noder i graf-runtimen din, verifiser at den faktisk stopper
3. Skriv seed-generator (timestamp+random+hash) og commit den — brukes i neste content-batch
4. Test Ollama som lokal worker-node i én eksisterende agent-graf, mål latency mot cloud-API
5. Instrumenter én agent-pipeline med enkel span-logging, finn ett faktisk feilpunkt
6. Splitt én "gjør alt"-agent i to smale spesialist-agenter, sammenlign output-kvalitet
7. Legg prompts for AI Empire-stacken i git, gjør første commit av prompt-historikk
8. Kjør ett 3-agent debate-loop på et reelt patentspørsmål, logg konklusjonen
9. Skriv global kill-switch for alle autonome loops, test at den faktisk trigger
10. Dokumenter plugin-arkitekturen for agent-tools formelt — beskytt før du deler den åpent

## Vibe coding / 48-timers bygg (11-18)
11. Velg én idé fra RESEARCH_NODE-lista, sett 48t-klokke, start bygging nå

13. Test Figma MCP på ett UI-konsept, mål tid fra design til kjørbar kode
14. Legg AI-generert smoke-test på siste vibe-code-prosjekt før du går videre
15. Sett opp auto-deploy-hook til staging for neste miniapp
16. Konverter én idé til én selvstendig HTML-fil, del den samme dag
17. Kjør refactor-agent over natten på ett repo, review resultatet i morgen
18. Definer token-sett (farger/typografi) for gonzo Banksy-merkevaren i kode
