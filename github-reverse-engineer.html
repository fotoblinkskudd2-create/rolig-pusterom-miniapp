Komplett prompt klar til å limes inn i en AI-assistent

Slik bruker du den

  1. Lim inn lenken til et offentlig GitHub-repo (f.eks. https://github.com/eier/repo) og trykk «Analyser».
  2. Verktøyet henter repo-info, mappestruktur, README og nøkkelfiler (package.json, requirements.txt osv.) direkte fra GitHubs API i nettleseren din.
  3. Les gjennom kortene for stack, struktur og filer for å forstå prosjektet raskt (reverse engineering).
  4. Nederst finner du et ferdig utformet prompt. Bytt ut «[SETT INN HVA DU ØNSKER]»-linjen med det du faktisk vil ha gjort — f.eks. «gjenskap denne appen fra bunnen av», «porter dette til Python», «finn sikkerhetshull», eller «bygg videre med funksjon X».
  5. Kopier prompten og lim den inn i en AI-kodeassistent (Claude, Claude Code, ChatGPT osv.) for å komme raskt i gang.
