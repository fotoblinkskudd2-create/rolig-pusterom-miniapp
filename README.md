# rolig-pusterom-miniapp
Rolig mini-app for å dempe stress og nedstemthet. 4 sider: Innsjekk, Pusterom, Små grep, Historikk. Pure HTML/CSS/JS med lokal lagring.

Pusterom-siden har tre pustemønstre (Rolig 4-2-6, Boks 4-4-4-4, Dyp 4-7-8) med riktig timet animasjon og en rolig fargeskiftende bakgrunn. Historikk viser streak (dager på rad) og en 7-dagers humørtrend, og hver sjekk-inn kan slettes. Appen er installerbar som PWA (manifest.json + sw.js) og respekterer prefers-reduced-motion.
