# rolig-pusterom-miniapp

Rolig PWA. 4 sider: Innsjekk, Pusterom, Små grep, Historikk. Pure HTML/CSS/JS. Lokal lagring, mørk minimal UI.

**2.0 (20.11.2026):** full PWA (manifest + service worker, installerbar + offline), tale-input på notat (Web Speech API, no-NO), eksport av historikk som JSON/CSV, daglig recovery-plan, OpenClaw-hook (`openclaw/recovery-plan.agent.json`), nytt mørkt designsystem.

**1.1 (29.08.2026):** nav-fix, lokal-first-linje, export av historikk, Isolation Mirror bundet til Labben/Grok-bot.

Åpne `index.html` – eller kjør `python3 -m http.server` og åpne `http://localhost:8000` (service worker krever http). Les `RUN.md`.
