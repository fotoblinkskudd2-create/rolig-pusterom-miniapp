# rolig-pusterom-miniapp
Rolig mini-app for å dempe stress og nedstemthet. 4 sider: Innsjekk, Pusterom, Små grep, Historikk. Pure HTML/CSS/JS med lokal lagring.

## github-reverse-engineer.html
Frittstående verktøy: lim inn en offentlig GitHub-repo-lenke, og få en reverse engineering av stack, mappestruktur og README, pluss et ferdig komplett prompt du kan bruke i en AI-kodeassistent. Kjører helt i nettleseren mot GitHubs offentlige API — ingen server eller nøkkel nødvendig.
