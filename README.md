# rolig-pusterom-miniapp
Rolig mini-app for å dempe stress og nedstemthet. 4 sider: Innsjekk, Pusterom, Små grep, Historikk. Pure HTML/CSS/JS med lokal lagring.

Åpne `index.html` for denne appen.

## VENTIL

`ventil.html` er en frittstående prototype av **VENTIL** — "Slipp ut trykket. Ikke ut i verden." — en trygg trykkventil for aggresjon, bygget på prinsippet Release → Regulate → Reflect → Redirect (ren catharsis alene forsterker ofte sinne, så utløp følges alltid av en obligatorisk nedregulering).

Flyt: stor rød «VENTIL NÅ»-knapp → valgfri intensitetssjekk → utløp (skriv-og-brenn, knus, eller skrik med mikrofon) → tvungen 60–90 sek boksepust-nedregulering → valgfri refleksjon → forslag til konstruktive neste steg.

Personvern: alt du skriver eller sier under et utløp holdes kun i minnet og forsvinner når du destruerer det — det lagres aldri, verken lokalt eller i sky. Kun anonyme tellere (antall økter, intensitet, tidspunkt) lagres i `localStorage`. Appen er ikke terapi; ved krise viser den norske hjelpelinjer (113 / 116 123 / Kirkens SOS).

Pure HTML/CSS/JS, ingen avhengigheter, fungerer offline. Neste steg mot full spec (se prosjektnotater): on-device AI for Valve Keeper/Cool-down/Reflector-promptene, custom smash-mål, mønstergjenkjenning, og en React Native/Expo-versjon for iOS/Android.
