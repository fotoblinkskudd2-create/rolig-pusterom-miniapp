# rolig-pusterom-miniapp
Rolig mini-app for å dempe stress og nedstemthet. 4 sider: Innsjekk, Pusterom, Små grep, Historikk. Pure HTML/CSS/JS med lokal lagring, ingen backend eller avhengigheter.

## Struktur
- `index.html` – markup for de fire sidene og bunnnavigasjonen
- `style.css` – alt av styling
- `app.js` – sidebytte, pusteanimasjon, sjekk-inn, små grep og historikk (lagres i `localStorage`)

## Kjøre lokalt
Åpne `index.html` direkte i en nettleser, eller kjør en enkel lokal server, f.eks. `npx serve .`.
