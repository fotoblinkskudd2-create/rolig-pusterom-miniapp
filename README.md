# rolig-pusterom-miniapp
Rolig mini-app for å dempe stress og nedstemthet. 5 sider: Innsjekk, Pusterom, Små grep, Speil, Historikk. Pure HTML/CSS/JS med lokal lagring – ingen data forlater enheten.

**Speil** er en refleksjonsside: skriv noen ord eller legg ved et bilde (kun forhåndsvist lokalt, aldri lagret) og få tre små steg, en kort speil-tekst, og en kopierbar prompt for AI-bildegenerering (Midjourney/Flux-stil) hvis du vil lage kunst av stemningen selv.
