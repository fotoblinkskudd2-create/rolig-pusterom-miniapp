# Prebunk

Inokulering = varsel + svekket dose + motargument. Lær **teknikken**, ikke den enkelte myten. Da virker det på myter som ikke er funnet opp ennå.

## De seks teknikkene (Roozenbeek m.fl. 2022 + FLICC)
| id | Teknikk | Avslører seg ved |
|---|---|---|
| emosjon | Emosjonelt språk | frykt-/sinneord, VERSALER, !!!, «sjokkerende» |
| usammenheng | Usammenheng | to påstander som ikke kan være sanne samtidig |
| dilemma | Falskt dilemma | «enten … eller», «hvis du ikke X, er du Y» |
| syndebukk | Syndebukk | én gruppe får skylden for et sammensatt problem |
| personangrep | Personangrep | angriper personen, ikke argumentet |
| ekspert | Falsk ekspert | tittel uten fagfelt, «lege avslører», «innsider» |

## Oppskrift for én øvelse
1. Varsle: «Noen vil prøve å lure deg med X.»
2. Vis en oppdiktet post med teknikken.
3. La brukeren gjette.
4. Forklar ordet/grepet som avslørte den.

Implementert i `motgift.html` → fanen **Tren**.
