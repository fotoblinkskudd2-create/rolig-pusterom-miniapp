# RUN

## Åpne lokalt

1. Last ned hele mappa.
2. Åpne `index.html` i Safari eller Chrome. Alt virker unntatt offline-cache (service worker krever http/https).

## Installer som app (anbefalt)

1. Legg mappa på GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
2. Åpne URL-en på telefonen.
3. iPhone: Del → Legg til på Hjem-skjerm. Android/Chrome: «Installer app».
4. Etter første besøk virker den uten nett.

Ingen server. Ingen konto.

## Hva som lagres lokalt

| Nøkkel | Innhold |
|--------|---------|
| `checkins` | tid, humør 1–5, valgfri note |
| `doneActions` | hvilke «små grep» som er merket i dag (gamle dager slettes) |

Ingenting går på nett. Isolation Mirror viser bildet kun i denne fanen. Filen lastes ikke opp.

## Export

Historikk → «Ta historikken med deg (.txt)» → `pusterom-historikk.txt`.

## Fyrlykt

Sjekk inn 😔 eller 😕 → kort med 116 123 (Mental Helse), 22 40 00 40 (Kirkens SOS), 113. Også tilgjengelig fra Historikk → «Trenger du noen å snakke med?».

## Isolation Mirror → Grok-bot

Skriv note → Generer → Kopier prompt → lim i Labben eller Grok-bot med `/lab`.
