## How to read the numbers

- Market figures are **ranges with a named source type** (e.g. "WHO 2025", "KFF analysis of ACA marketplace data"). Treat them as directional. Each one is flagged for re-checking against the primary source before it goes into a pitch deck.
- Unit economics are **bottom-up models** with stated assumptions. They are not observed data.
- "2025 stack" means technology that was generally available in 2025: hosted frontier LLM APIs, on-device small models (Apple Foundation Models framework, Core ML, Gemini Nano), Whisper-class speech recognition, pgvector, and standard mobile/web tooling. Nothing here depends on unreleased capability.

## Relationship to this repo

The lead concept, **Rolig Companion**, is the commercial version of the `index.html` + `isolation-mirror.html` mini-app in this repo. The prototype already proves the core loop (check-in → breathe → small action → local history), and it already keeps every byte on the device. That local-first design is the wedge the whole recommendation is built on.

> Not medical, legal or financial advice. Concepts touching health, debt and investing need jurisdiction-specific regulatory review before launch.
