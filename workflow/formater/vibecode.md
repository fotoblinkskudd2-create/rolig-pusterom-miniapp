# Løype: Vibecode

Rask prototype bygget i samtale med AI. Ett HTML-ark, ingen byggesteg. Pusterom og Isolation Mirror er vibecode.

## LAG
1. **Én fil.** `index.html` med inline CSS/JS. Ingen rammeverk før det gjør vondt uten.
2. **Prompt-kjede i loggen.** Lim de viktigste promptene inn i prosjektkortet. Det er kildekoden din.
3. **Lokal-først fra første linje.** localStorage, ingen innlogging, ingen fetch mot ukjente tjenester.
4. **Si det i UI.** Én linje: «Alt blir på denne enheten.»
5. **Commit etter hver fungerende bit.** Små commits, norske meldinger.

## HULL (vibecode)
- Åpne fila i ny nettleser uten data. Hva skjer?
- Trykk på alt. `alert()`, døde knapper, nav som ikke følger med?
- Kan brukeren ta med seg dataene sine (export)?
- iPhone Safari: test på ekte telefon, ikke bare devtools.

## Når vibecode blir kode
Flytt til `kode.md`-løypa når: flere enn ca. 600 linjer, mer enn én person jobber på det, eller det trengs tester.

## LEVER
README (hva, versjon, dato) + RUN.md (åpne, hva lagres, export). Se `maler/leveranse.md`.
