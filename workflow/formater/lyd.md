# Løype: Lyd og andre formater

Podkast, talenotat, lydversjon av tekst. Også: PDF, presentasjon, plakat, merch — samme steg, egen sjekkliste.

## Lyd — LAG
1. Manus eller stikkord (→ `tekst.md`).
2. Opptak i stille rom. Ett takes per avsnitt er nok.
3. Descript: fjern fyllord, normaliser lyd, eksporter.

## Lyd — HULL
- Lytt på mobilhøyttaler. Hører du alt?
- Første 10 sekunder: vet lytteren hva dette er?

## Andre formater — sjekkliste
- [ ] Hvem skal holde det i hånden / se det?
- [ ] Hvilket filformat forventer de (PDF, PPTX, PNG, trykk)?
- [ ] Hvilket format finnes allerede (tekst/bilde/video) som kan gjenbrukes?
- [ ] HULL-test med én person som ikke har sett det før.

## LEVER
Fil + kort beskrivelse + hvor det ligger. Linje i `LOGG.md`.
