# LAB-prompt

Lim i Labben eller Grok-bot med `/lab`. Formatet er hentet fra Isolation Mirror.

```
Grok-bot runtime. /lab. Klasse M.
PROBLEM: <problem i én setning>
BRUKER: <hvem, konkret>
RAMMER: 48t, lokal-first, ingen marketplace, ingen app+sky
DNA: <2–3 ingredienser som skal være med>
LEVERANSE: <ideer | brief | manus | prototype>
FORMAT: <tekst | vibecode | kode | bilde | video | lyd>
Seed 7. Drepe minst 3. IRP på overlevende #1.
Skriv IDE ≤3 setninger på nynorsk. Stopp.
Ikke nytt OS.
```

## Etterpå (skriv inn i prosjektkortet)
- Overlevende #1: <≤3 setninger>
- Drept: 1) … fordi … 2) … fordi … 3) … fordi …
- IRP-funn: <hva kan gå galt>
