Grunnlag: `01-research.md`. Kryssmønsteret derfra styrer alt: **signal → plan → handling**, ikke enda en dagbok.
Stack-forkortelser: RN = React Native, PWA = installerbar web-app, LLM = GPT/Claude API, SB = Supabase, Node = Node/Express, BLE = Bluetooth-sensor.
